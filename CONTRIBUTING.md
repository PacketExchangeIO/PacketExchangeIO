# Contributing

This repository holds the PacketExchange profile page. To contribute code or documentation, open an issue or pull request in the relevant repository:

- [packetexchange-node](https://github.com/PacketExchangeIO/packetexchange-node)
- [packetexchange-python](https://github.com/PacketExchangeIO/packetexchange-python)
- [packetexchange-examples](https://github.com/PacketExchangeIO/packetexchange-examples)
- [packetexchange-openapi](https://github.com/PacketExchangeIO/packetexchange-openapi)
- [packetexchange-mcp](https://github.com/PacketExchangeIO/packetexchange-mcp)

Fixes to the profile itself, such as a broken link or a typo, are welcome here. Changes are checked with [markdownlint](https://github.com/DavidAnson/markdownlint-cli2); to run it locally:

```sh
npx markdownlint-cli2 "*.md"
```

For help with your account or the API, email [support@packetexchange.io](mailto:support@packetexchange.io). To report a security vulnerability, follow [SECURITY.md](SECURITY.md).

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). By taking part, you agree to follow it.
